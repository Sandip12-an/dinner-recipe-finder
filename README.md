# 🍲 What’s for Dinner? — Recipe & Ingredient Finder

A fast, responsive, client-side web application to discover dinner recipes based on ingredients you have at home. Powered by [TheMealDB API](https://www.themealdb.com/).

![License](https://img.shields.io/badge/License-MIT-green.svg)
![Vanilla JS](https://img.shields.io/badge/Tech-HTML5%20%7C%20CSS3%20%7C%20Vanilla%20JS-orange.svg)

---

## ✨ Features

- 🔍 **Smart Ingredient & Name Search**: Search by what's in your pantry (e.g. `chicken`, `paneer`, `egg`) or dish names (`pasta`, `curry`).
- 🎲 **"Surprise Me!" Button**: Generates a random meal idea with one click.
- 📋 **Interactive Ingredients Checklist**: Check off items as you cook.
- 📖 **Full Cooking Instructions**: Clear step-by-step directions.
- 🎬 **YouTube Tutorials**: Direct video links for visual cooks.
- ❤️ **Persistent Favorites**: Save recipes to your browser using `localStorage`.
- ⚡ **Filter Pills**: One-tap categories for Vegetarian, Seafood, Dessert, Chicken, and more.
- 📱 **Mobile-First Responsive Design**: Works on smartphones, tablets, and desktops.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic layout & accessibility
- **CSS3**: Modern variables, glassmorphism, flexbox & grid
- **Vanilla JavaScript**: ES6+, Fetch API, LocalStorage
- **API**: [TheMealDB](https://www.themealdb.com/api.php) (Free, no API key required)

## 🚀 Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/whats-for-dinner.git
   ```
2. Navigate to the project folder:
   ```bash
   cd whats-for-dinner
   ```
3. Open `index.html` directly in any browser, or use a local server:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000`.

## 🌐 Deploy to GitHub Pages (Free)

1. Go to your repository settings on GitHub.
2. Under **Pages** (in the left sidebar), select:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `root`
3. Click **Save** — your site will be live at `https://<your-username>.github.io/<repo-name>/`!
